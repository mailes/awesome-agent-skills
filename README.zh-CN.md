## 为什么做这个清单

Agent 能力是新的「应用商店」，但好技能散落在各个仓库和帖子里。
这个清单把可以直接一键安装的免费技能集中维护，
每个都附演示视频与安装页，安装后即可在你的 Agent 中运行。

## 一步安装

1. 点开下面任意技能（或 WorkSkill 任意页面）。
2. 点 **Install**——免费技能无需注册账号。
3. Agent 即刻就绪；在 Claude Code / Codex / Cursor 里直接说出你要的结果。

机器可读数据：[`data/free-skills.json`](data/free-skills.json) · 重新生成：`python3 scripts/update.py`
